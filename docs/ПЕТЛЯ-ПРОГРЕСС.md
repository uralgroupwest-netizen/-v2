## Оговорки честности

1. **Раздел Б планки не снят с изображения.** Механики для страницы выведены из
   ориентиров, записанных в `CLAUDE.md` (Linear, Stripe, Vercel), а не измерены
   по конкретному эталону. Это слабее, чем требует метод, и критик ремесла судит
   их без пары для сравнения.
2. **Слепота критика ремесла неполная.** Он выносит вердикт по паре A/B первым
   действием, до того как увидит остальные кадры страницы, — но после этого
   может догадаться, какой из двух был наш. Инструкция требует зафиксировать
   вывод до перехода ко второму этапу.
3. **Заставка кадрами не судится.** Её механики (отрисовка штрихом, распад
   частиц, переход в тёмное) видны только в движении; статические кадры страницы
   их не показывают. Отдельная раскадровка при необходимости — `--timeline`.
