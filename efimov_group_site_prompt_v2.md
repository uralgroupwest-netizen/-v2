### Эксклюзивный · Статусный · B2B-центричный с открытым входом для B2C

---

## Роль и задача

Ты — старший Product Designer и Frontend Lead с опытом в B2B SaaS и консалтинговых сайтах уровня Stripe, Linear, McKinsey Digital. Создай сайт, который за **первые 2–5 секунд** передаёт: «это серьёзная компания, которой можно доверять дорогие задачи» — одновременно для владельца бизнеса и для частного человека с нестандартной задачей.

Главный критерий успеха: посетитель не должен сомневаться в том, что Efimov Group — это выбор людей, которые ценят результат, а не эксперимент.

## Двойная аудитория: психологические режимы

### B2B-режим (Efimov Tech + Efimov Consult)
Это рациональный покупатель. Он:
- Принимает решение на основе ROI, кейсов и доверия к команде
- Ищет гарантии и договор, а не обещания
- Реагирует на: цифры, логотипы клиентов, процесс, конкретный следующий шаг
- Боится: потратить деньги и не получить результат, «очередного подрядчика»

**Что транслирует сайт в B2B-режиме:**
- Мы работаем по договору с KPI
- Вот конкретные результаты, которых добились клиенты
- Вот наш процесс — никакой магии, только система
- Вот кто именно с вами работает

### B2C-режим (Efimov Urban + частично Tech)
Это эмоциональный покупатель. Он:
- Принимает решение на основе ощущения надёжности и простоты
- Хочет знать: «это безопасно?», «сколько стоит?», «с чего начать?»
- Реагирует на: отзывы обычных людей, понятный процесс, гарантию
- Боится: нарваться на мошенников, переплатить, попасть в сложный процесс

**Что транслирует сайт в B2C-режиме:**
- Начните с одной задачи — это просто
- Цены прозрачные, условия понятные
- Реальные отзывы реальных людей
- Если что-то пойдёт не так — мы разберёмся

## Архитектура доверия: первые 2–5 секунд

Это самый важный раздел промпта. Всё, что видно до скролла, должно содержать минимум 5 сигналов статуса и доверия.

### Слой 0 — Trust Bar (тонкая полоска над шапкой)
Высота: 36px. Фон: чуть темнее шапки.
Содержимое (слева направо):
```
● Официальный партнёр amoCRM  ·  г. Смоленск  ·  Работаем с [год]  ·  [N]+ клиентов
```
Справа: `✓ Ответим в течение 30 минут`

Эффект: посетитель ещё не видел ни логотипа, ни заголовка, но уже знает: это легитимная, давно существующая компания с конкретным партнёрством.

### Слой 1 — Навигация
- Логотип: `Efimov Group` крупно + `Смоленск` мелко (город снимает «это московские ребята, нам не подойдут»)
- Три департамента как пункты меню — структура компании читается из nav
- Кнопка «Оставить заявку» — всегда в правом углу, sticky на скролле
- На мобильном: sticky header с номером телефона и кнопкой Telegram

### Слой 2 — Eyebrow над заголовком
Маленький pill-бейдж с точкой-индикатором:
```
● Системный интегратор · 3 направления · 1 партнёр
```
Цвет точки: зелёный (сигнал «онлайн», «активны»).

### Слой 3 — Заголовок H1
Формула: **Результат** + **Условие** + **Контраст с болью**

Пример (финальный текст — задача копирайтера):
```
Ваш бизнес растёт,
когда процессы работают без вас
```
Вторая строка приглушена (цвет #3d4455) — контраст веса, а не только цвета.
Размер: 44–52px, font-weight 800, letter-spacing -0.03em.

### Слой 4 — Подзаголовок
Не описывает компанию. Описывает, что получит клиент:
```
Автоматизируем продажи, выстраиваем отдел и берём задачи, 
которые съедают ваше время. Три департамента — одна точка входа.
```
Ключевое слово **«одна точка входа»** — снимает возражение про «слишком разные услуги».

### Слой 5 — Двойной CTA
```
[Подобрать решение →]   [Посмотреть кейсы]
```
Primary: заливка, ведёт в квиз.
Secondary: outline, ведёт к кейсам. Не «Узнать больше» — это ни о чём.

### Слой 6 — Социальное доказательство в одну строку
Четыре метрики горизонтально, разделённые чертой:
```
80+ клиентов  |  140+ проектов  |  5 лет на рынке  |  94% повторных обращений
```
Числа крупно (28px, bold), подписи мелко, приглушённо.
**Последняя метрика — самая сильная.** 94% повторных обращений — это то, что не купить рекламой.

### Слой 7 — Полоса департаментов (прямо над footer или как финал hero)
Тёмная полоса с тремя ячейками:
- `● Efimov Tech` / amoCRM, автоматизация, интеграции / [бейдж «partner amoCRM»]
- `● Efimov Consult` / Аудит, регламенты, РОП в аренду
- `● Efimov Urban` / Городские задачи под ключ

Точки: синяя, фиолетовая, зелёная — соответствуют акцентным цветам каждого департамента.

### Секция 4 — Процесс (одинаковый для всех)

**Заголовок:** `От звонка до результата — понятный процесс`

**4 шага в горизонтальной линии:**

1. **Заявка** — Оставляете запрос любым способом: форма, Telegram, звонок
2. **Диагностика (бесплатно)** — Разбираем задачу, предлагаем решение с бюджетом
3. **Работа по договору** — Фиксируем KPI и сроки. Никаких сюрпризов
4. **Результат + отчёт** — Сдаём работу с отчётностью. Поддержка после

**Ключевые усилители в каждом шаге:**
- Шаг 2: слово «бесплатно» — снижает барьер входа
- Шаг 3: «по договору» + «KPI» — это B2B-сигнал доверия
- Шаг 4: «отчёт» + «поддержка» — закрывает страх «бросят после оплаты»

## Визуальный стиль — детальные требования

### Уровень качества
**Ориентир:** Linear.app + Stripe + Vercel — чистая, уверенная типографика, тёмный hero, точные пропорции, ничего лишнего.
**Не делать:** Яркие розово-оранжевые градиенты «во весь фон», clip-art иконки, шаблонные фото с Shutterstock, мигающие элементы.

### Палитра

| Элемент | Hex |
|---|---|
| Фон dark (Hero, тёмные секции) | #0D0F14 |
| Фон тёмный вторичный (Trust bar, полосы) | #13161E |
| Фон светлых секций | #F8F9FB |
| Акцент Efimov Tech | #1A6FE0 |
| Акцент Efimov Consult | #7F77DD |
| Акцент Efimov Urban | #1D9E75 |
| Текст основной (светлые секции) | #1A1D23 |
| Текст вторичный | #6B7280 |
| Текст на тёмном фоне | #E5E7EB |
| Текст мuted на тёмном | #8892A0 |
| Разделители тёмной темы | #1E2230 |
| Разделители светлой темы | #E5E7EB |

**Единственный способ выделить элемент** — цвет акцента нужного департамента. Никаких «random» цветных пятен.

### Типографика

```
Display (H1):  52–64px / weight 800 / tracking -0.03em / line-height 1.06
H2 (заголовки секций): 36–42px / weight 700 / tracking -0.02em
H3 (заголовки карточек): 20–24px / weight 600
Body: 15–16px / weight 400 / line-height 1.65
Label/caption: 11–12px / weight 500 / tracking 0.04em / uppercase
```

Шрифт: **Inter** (основной) или **Manrope** (если нужна мягче). Проверить рендер кириллицы на всех размерах обязательно.

### Анимации — строгий набор

| Эффект | Где использовать |
|---|---|
| Fade-in + translateY(20px→0), 400ms ease-out | Появление блоков при скролле |
| Count-up при попадании в viewport | Числовые метрики |
| Hover lift (translateY -4px, 200ms) | Карточки департаментов, кейсы |
| Underline grow on hover | Ссылки в nav и тексте |
| Cursor magnetic (притяжение к кнопкам, ±15px) | Только desktop, только CTA-кнопки |
| Progress bar анимация | Квиз, шаги процесса |

**Запрещено:** Parallax с задержкой на медленных устройствах, spin-анимации, bounce, резкие flash.

### Иконки

Использовать **Phosphor Icons** или **Heroicons** — outline-стиль, 24px, цвет соответствует акценту раздела. Не миксовать разные библиотеки в рамках одной страницы.

### Пространство

Минимальный padding секций: **120px top/bottom** (desktop), **64px** (mobile).
Между блоками внутри секции: **48px**.
Плотность контента: лучше меньше элементов, но с воздухом, чем много и тесно. Пустое пространство — это роскошь, которая стоит больше, чем ещё один блок.

## Технические требования

### Стек
- **Framework:** Next.js 14+ (App Router) или Astro 4+
- **Styles:** Tailwind CSS v3+
- **Animations:** Framer Motion (React) или GSAP ScrollTrigger
- **Forms:** собственный API route → передача в amoCRM через webhook

## Копирайтинг — правила и запреты

### Правила
1. **Конкретика > абстракция.** «+38% конверсия за 4 недели» > «улучшим ваши продажи»
2. **Язык результата.** «Больше ни одной потерянной заявки» > «настраиваем CRM»
3. **Говорить с владельцем, не с менеджером.** «Ваши деньги», «ваш рост», «ваше время»
4. **Снимать возражения до того, как они возникнут.** «Бесплатная диагностика», «работаем по договору», «без предоплаты при первом обращении»
5. **Числа везде, где возможно.** Не «быстро», а «за 30 минут». Не «много клиентов», а «80+»
6. **Для Urban — простой язык.** B2C читает иначе. «Опишите задачу» > «оставьте заявку на услугу»

### Запреты
- «Качественные услуги» / «профессиональный подход» / «команда экспертов» — без подтверждения
- «Мы рады вам предложить» — канцелярит
- «Наша компания была основана...» — никому не интересно в первом экране
- Обещания без цифр: «значительно увеличим» вместо «в среднем +30%»
- Жаргон без расшифровки: «ROI», «NPS», «CJM» без пояснения — для B2C убийственно
