ФАЙЛЫ
  *.svg  — вектор, главный формат. Из него делается любой размер без потерь.
  png/   — растр для быстрых задач: соцсети, презентации, письма.

  full-color        основной лок: знак + надпись. Для светлого фона.
  full-dark-bg      для тёмного фона.
  full-mono-black   один цвет. Печать, факс, гравировка, штамп, вышивка.
  full-mono-white   один цвет на тёмном.
  mark-*            только знак, без надписи.
  compact-*         только «G». Для мест, где лок нечитаем: аватарка, фавикон,
                    иконка приложения, штамп малого размера.
  favicon-*.png     16 / 32 / 64 / 180 / 512 px.

ПРАВИЛА
  1. Охранное поле — не меньше высоты красной полосы со всех сторон.
     Ничего в это поле не заходит: ни текст, ни картинки, ни край макета.
  2. Минимальный размер полного лока — 110 px по ширине на экране,
     30 мм в печати. Меньше — только компактный знак.
  3. Пропорции не меняются. Растягивать, наклонять, поворачивать — нельзя.
  4. Не добавлять тени, объём, свечение, обводку, градиенты.
  5. На пёстрой фотографии — только монохромная версия на плашке.
  6. Цвета не заменяются. Красный только #E01F26.

ЧТО ЕЩЁ НЕ СДЕЛАНО
  1. Проверка на сходство с чужими товарными знаками по базе Роспатента.
     Обязательна до вложений в бренд: пошлины при отказе не возвращаются.
  2. Буквы в надписи нарисованы геометрически с нуля и правами не обременены,
     но перед подачей на регистрацию их стоит показать патентному поверенному
     вместе со знаком.
  3. Регистрация комбинированного товарного знака: госпошлины от 35 000 руб.
     за один класс МКТУ. Классы под ваши направления: 35, 42, 37, 45.
